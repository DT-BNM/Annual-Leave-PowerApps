DART Annual Leave Schedule
- Built on PowerApps
- Backend on Sharepoint Site

Pages/Use Case
- Front Page
    - Can view the overview
    - Can view the public holidays in malaysia for the year
    - Can edit user profile
- Dashboard Overview
    - To view monthly calendar where the we can see the leave utilised by staff (if any)
    - Weekends would be blocked out
    - Public holidays would be grayed out
    - At the top, we could have like card counts for that specific month on what type and how many of those leaves are utilised
    - For the filters, could filter based on the months, years
    - User can directly input at the selected date of when they've applied for their leave
- User Profile
    - User has to input things such as their AL amount for the year, study leaves, etc.
- Public Holidays
    -   Page to view all the public holidays for the year
    -   Allow for user amendment to edit the public holidays
